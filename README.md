# 📧 Spam Detection System

This is a simple Machine Learning project that detects whether a message is **Spam or Not Spam (Ham)**.

---

## 🚀 Features

* Classifies messages as Spam or Not Spam
* Uses basic Machine Learning
* Simple and easy to understand
* Fast prediction

---

## 🛠️ Technologies Used

* Python
* Scikit-learn
* Pandas

---

## 📂 Project Files

```id="wz3y7a"
app.py
model.py
preprocess.py
requirements.txt
dataset/
```

---

## ⚙️ How to Run

1. Install dependencies:

```id="y3r3qj"
pip install -r requirements.txt
```

2. Run the project:

```id="c3s8x2"
python app.py
```

---

## 🔄 How it Works

1. Load dataset
2. Clean the text
3. Convert text into numbers
4. Train the model
5. Predict Spam or Not Spam

---

## 📊 Output

* Gives result as:

  * Spam
  * Not Spam
